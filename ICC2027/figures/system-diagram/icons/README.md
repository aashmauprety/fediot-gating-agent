# Icon attribution

Icons in this folder are derived from [Font Awesome Free](https://fontawesome.com)
(server, robot, microchip, database, circle-check, circle-question,
user-shield, lock, shield-halved, magnifying-glass, bell,
temperature-half, video, house-signal), licensed under
[CC BY 4.0](https://fontawesome.com/license/free). Recolored from the
original black glyphs and converted to PDF for use in the system
diagram (`../gating_system_diagram.tex`). The bell/thermometer/camera
icons stand in for real N-BaIoT device types (doorbell, thermostat,
security camera/webcam) rather than a generic "gateway" icon.
