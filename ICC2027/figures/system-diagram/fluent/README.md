# Icon attribution

Icons in this folder are the "3D" style assets from
[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji),
licensed under the [MIT License](https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE).
Used unmodified (bell, thermometer, movie camera, house, desktop
computer, robot, magnifying glass tilted right, locked, gear, shield,
check mark button, red question mark, bust in silhouette, file
cabinet) in the system diagram (`../gating_system_diagram.tex`).
